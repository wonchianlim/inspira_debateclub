## 2. 规范**没有说、必须做出来**的判断

Phase 8 有四处规范留白，每一处我都做了判断并把理由写进代码注释：

| 判断 | 我的选择 | 理由 |
|---|---|---|
| 教练笔记"私人"是私对谁 | **只有写笔记的教练本人**（连管理员也看不到） | 笔记是工作草稿。管理员能看，教练就会**为被看到而写**，失去如实记录不确定观察的作用 |
| 教练笔记是否进审计 | **不进** | 审计会复制整行正文到管理员能看到的地方；而审计的目的是竞赛完整性，不是私人草稿。代价（无痕迹）已写明 |
| 学生趋势需要多少场 | **4 场**（`MIN_DEBATES_FOR_TREND`） | 少于此，"最近两场 vs 前两场"是噪声，给结论会**误导学生** |
| 教练能否看到学生具体分数 | **看不到**（只给场次与赛制） | §17 把教练权限列为**不能自行决定**的事项 |

**每一处都写清了"如果产品负责人要改成另一种，改动在哪里"。**

## 3. 贯穿本阶段的一条约束：**不做排名**

- 学生侧：JWSD §49、PF §61、BP §49 都写 "Do not immediately create public rankings."
- 裁判侧：规范**完全没有**要求裁判之间的比较

因此两个统计模块的**接口形状**都是"只接受一个人的数据"，
并有测试**断言产出里没有** `rank` / `percentile` / `leaderboard` / `peerAverage` 等字段。

> **把闸门做在接口形状上，而不是靠调用方自觉 —— 后者迟早会被绕过。**
>
> 裁判的分数松紧尤其敏感：一旦公开，"这位裁判给分低"会变成**选裁判**的依据，
> 而规范第 10 节要的是**校准**（尺度一致），不是**挑选**。

### 三条测试抓出的"假检查"

1. **断言测不到它声称的东西**：`update coach_notes set body=...`（无 where）期望 0 行、
   实际 1 行 —— 因为表里只有教练**自己的**笔记，改到 1 行**是正确行为**。
   要测"改不动别人的"，必须**先有别人的笔记**。
2. **核对身份错了**：验证"正文没被改动"时用教练身份查询，查出来是 NULL ——
   那既不能证明改没改，也**无法区分"被拦住"与"没这条记录"**。
3. **凭记忆猜夹具**：把两位**学生**当成"另一位教练"。夹具里只有一位教练。

## 6. 已知限制

1. **教练看到的是"全社的学生"** —— 系统里没有教练与学生的关联表。
   这一点**直接写在界面上**，而不是让教练以为这就是他带的学生。
