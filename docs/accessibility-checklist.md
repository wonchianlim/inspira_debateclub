# 无障碍人工复查清单

> **为什么要人工过一遍**：规范第 16 节的 Definition of Done 要求
> "accessibility basics are verified"。自动化能查的那部分已经做了
> （`npm run check:a11y` —— 表单控件的可访问名称、图片 alt），
> 但**对比度、焦点顺序、键盘能否走完流程、屏幕阅读器实际读出什么**
> 需要真实浏览器与人的判断。
>
> **怎么用**：按下面的顺序走一遍，任何一步"不对劲"就记下来。
> 不需要你懂技术 —— 只要求你**试着不用鼠标**把事情做完。
> 遇到卡住的地方，那就是问题。

---

## 一、只用键盘走一遍主流程（最重要的一项）

把鼠标放到一边。**只用 Tab、Shift+Tab、Enter、空格、方向键。**

> 为什么这一项最重要：用键盘能走通，屏幕阅读器和各种辅助设备才大概率能用。
> 如果键盘走不通，其他都不用测了。

按这个顺序走，每一屏都问自己三个问题：

| 顺序 | 页面 | 路径 |
|---|---|---|
| 1 | 登录 | `/login` |
| 2 | 注册 | `/register` |
| 3 | 学生报名活动 | 学生区域 → 活动 → 报名 → 选赛制偏好 |
| 4 | 管理员建活动 | 管理区 → 活动 → 新建 |
| 5 | 管理员生成配对 | 活动 → 配对 |
| 6 | 管理员生成比赛 | 活动 → 比赛安排 |
| 7 | 现场看板签到 | 活动 → 现场看板 |
| 8 | **裁判填评分表**（最关键） | 裁判区域 → 某场比赛 → 填表 |

**每一屏问三个问题：**

1. **Tab 键能走到每一个输入框吗？** 有没有哪个框"跳过去了"？
2. **走到的时候，看得出焦点在哪吗？** 有没有哪个控件被选中了却看不出来？
3. **Enter 或空格能触发按钮吗？**

**特别注意第 8 项（裁判填评分表）** —— 它是字段最多的一页，
而且里面有可重复列表（"+ 添加论点"、"删除"）与排名下拉。
**这是最可能出问题的地方。**

---

## 二、焦点可见性

- 用 Tab 走一遍，**每一步都能看出"现在在哪"吗？**
- 有没有控件的焦点框被截断、被遮住、或者与背景色几乎一样？

---

## 三、缩放与字号

- 浏览器缩放到 **200%**，页面还能用吗？有没有内容被切掉、横向滚动条乱跳？
- 系统字号调大之后呢？

---

## 四、颜色不是唯一的信息来源

- **"未读"标记**：如果它是靠颜色区分的，色弱的人能看出来吗？
  （提示：目前的实现**同时有文字角标"未读"**，所以这一项应当没问题 —— 请确认。）
- **验证错误提示**：只有红框、还是有文字说明？
- **胜负/名次标记**：有没有只靠颜色表达的状态？

---

## 五、屏幕阅读器（可选，但很有价值）

**Windows**：按 `Win + Ctrl + Enter` 打开「讲述人」。
**Mac**：按 `Cmd + F5` 打开 VoiceOver。

打开后走一遍上面第一项的流程，问自己：

- 它读出来的**控件名称**是不是人话？（例如"给这位学生的私人笔记"而不是"编辑框"）
- **按钮**读出来是"按钮"还是光秃秃的文字？
- **错误提示**会被读出来吗？

> ⚠️ 自动化脚本**只能**保证"每个控件都有名称"，
> **不能**保证读出来的名称**有意义**。这一步只有人能判断。

---

## 六、记下问题

发现问题时，请尽量写清：

1. **哪个页面**（把地址栏里的路径复制下来）
2. **你做了什么**（按了几次 Tab、点了什么）
3. **期望什么、实际什么**
4. 如果方便，**截个图**

**不用判断"这是不是无障碍问题"** —— 只要你觉得"这样用起来别扭"，
就记下来，我来判断。

---

## 七、这份清单**不覆盖**的

- **读屏软件的完整兼容性**（不同读屏软件差异很大，需要专业测试）
- **运动障碍相关的辅助设备**
- **认知负荷**（文案是否易懂 —— 这一项我另外尽力做了，
  界面上的提示都尽量写成完整的句子而不是术语）

这些超出"basics are verified"的范围，属于上线后可以继续改进的部分。

---

## 附：自动化已经覆盖的部分

`npm run check:a11y` 会在每次 `npm run check` 时运行，检查：

- 每个 `<input>` / `<textarea>` / `<select>` 都有可访问名称
  （自带 `aria-label`、或有 `id` 且存在对应的 `label htmlFor`）
- 每个 `<img>` 都有 `alt`

**它查不出**上面第一到第六节的任何一项。
